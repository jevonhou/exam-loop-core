# Roadmap

## v0.1 — trustworthy primitives

- [x] generic learning item, skill, attempt, and review-state contracts
- [x] deterministic spaced-review scheduler
- [x] adapter-driven session planning and evaluation
- [x] configurable checkpoints and remediation
- [x] versioned content-package validation
- [x] checksummed archives and atomic restore helpers
- [x] neutral fictional-certification example
- [x] public-file audit, unit tests, build, and local package
- [x] typed linting, formatting, public API type tests, and enforced coverage thresholds
- [x] fresh-consumer package verification and Node 22/24 CI configuration

Version `0.1.x` is distributed through GitHub Releases. Publishing to a package registry remains a later milestone.

## Later, not part of v0.1

- framework-specific UI packages
- hosted services, accounts, or synchronization
- real exam content or commercial question banks
- product-specific reward economies

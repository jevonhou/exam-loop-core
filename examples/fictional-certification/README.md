# Fictional Certification Example

This example proves that the engine can run a short learning loop without knowing the subject, interface, or storage platform.

The three prompts and all rules are original and deliberately fictional. They do not represent a real examination, authority, qualification, or operational procedure. Example content is dedicated under `CC0-1.0`, as declared inside the package metadata.

From the repository root:

```bash
npm run example
```

The script validates an untrusted content package, creates a deterministic session through an application-defined question adapter, evaluates simulated answers, schedules reviews, evaluates a checkpoint, and verifies a checksummed archive.

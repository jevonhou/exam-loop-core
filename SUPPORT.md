# Support

Exam Loop Core is currently a pre-release, maintainer-led project with no paid support or response-time guarantee.

Use the repository's structured forms and private reporting channel:

- [report a reproducible defect](https://github.com/jevonhou/exam-loop-core/issues/new?template=bug_report.yml);
- [propose a narrowly scoped, content-agnostic capability](https://github.com/jevonhou/exam-loop-core/issues/new?template=feature_request.yml);
- [report a vulnerability privately](https://github.com/jevonhou/exam-loop-core/security/advisories/new);
- keep product-specific implementation questions, private content, and learner data out of public issues.

Before reporting a defect, reproduce it on a supported Node version, reduce it to a minimal example, and run `npm run check` on a clean checkout when possible.
